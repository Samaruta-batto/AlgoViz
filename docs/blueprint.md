# **App Name**: TreeViz

## Core Features:

- BST Insertion: Visually demonstrate the step-by-step insertion of a node into a Binary Search Tree, with highlighting of the current node being examined.
- RBT Insertion: Animate the step-by-step insertion of a node into a Red-Black Tree, including rotations and recoloring to maintain RBT properties. Display messages when any RBT property is broken, and corrected using fixup
- RBT Deletion: Animate the step-by-step deletion of a node from a Red-Black Tree, including rotations and recoloring to maintain RBT properties. Displays messages for each of the 4 RBT fixup cases encountered. Comparison details should explain each comparision (for instance: color[w] == RED)
- B-Tree Insertion: Demonstrate B-Tree insertion with node splitting and key redistribution to visualize B-Tree properties.
- Tree Type Selection: Allow users to select which type of tree to visualize (BST, Red-Black Tree, B-Tree).
- B-Tree Order Control: Enables users to dynamically adjust the order ('T') of the B-Tree.
- Algorithm Stepping: Adds buttons and functionality that allow users to go step by step or auto play

## Style Guidelines:

- Primary color: Indigo (#4F46E5) for a calm, focused ambiance, inspired by concentration.
- Background color: Very light gray (#F9FAFB), providing a clean backdrop.
- Accent color: Teal (#38BDF8), drawing inspiration from the clarity often found in educational environments.
- Body and headline font: 'Inter' sans-serif for clear, accessible information presentation.
- Use simple, geometric icons for tree operations and navigation.
- Maintain a clean and spacious layout, ensuring each component is clearly defined.
- Employ subtle transitions and animations to highlight changes in the tree structure.
